# RayHistory

RayHistory will track family and local history projects from the Owen archive. This initial commit seeds the repository so it can be opened in hosted environments (GitHub Codespaces, cloud IDEs, etc.) and expanded as research notes, media references, and timelines are added.

## Getting Started

1. Clone the repository: `git clone https://github.com/theowenray/RayHistory.git`
2. Create or open a Codespace (or your preferred editor) to start adding content.
3. Organize future work into folders such as `docs/`, `media/`, or `timeline/` as needed.
